05 / HOW IT WORKS

From voice to security signal

A clear pipeline designed for rapid screening and explainable decisions.

01CAPTURE

Collect accessible audio

Microphone, supported call/tab audio, or an uploaded WAV sample.

02PREPROCESS

Standardize the signal

Audio is converted to the required format and prepared for model analysis.

03DETECT

Run two models

FoR provides the calibrated primary decision signal; AASIST supplies corroborating anti-spoofing evidence.

04DECIDE

Classify and log

The calibrated FoR boundary returns the risk verdict while metadata is recorded in scan history.

Built for responsible voice security
